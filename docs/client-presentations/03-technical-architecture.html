Auto-Detection

Console page queries /api/v1/vms/{name}/console-info to detect graphics type (VNC vs SPICE) and automatically selects the correct viewer. Falls back to serial if no graphics device is present.

Design Decisions

Serial uses direct tokio file I/O on /dev/pts/N -- socat's OPEN: mode fails on PTY devices. VNC proxy filters for type="vnc" only -- connecting SPICE ports with VNC protocol fails silently.

Security

Security Architecture

Defense-in-depth with validation at every layer

🔒

PAM Authentication

System-level login via Linux PAM. Users authenticate with their OS credentials. No separate user database required.

👥

RBAC Roles

Three roles: Admin (full access), Operator (VM lifecycle), ReadOnly (view only). Enforced at middleware level.

🔑

API Tokens

Prefixed with mach_ for programmatic access (legacy vs_ tokens remain valid until rotated). Token-based auth for CI/CD pipelines and automation scripts.

🛡

Input Validation

Names: alphanumeric + dash/underscore, 1-64 chars. vCPUs: 1-256. Memory: 64 MB - 1 TB. Disk: 0-10,240 GB. Integer overflow: checked_mul().

📂

Path Canonicalization

ISO paths, import paths, and template paths are canonicalized with is_file() checks. PTY paths must start with /dev/pts/. Prevents path traversal.

🌐

URI Allowlist

Migration endpoints only accept: qemu://, qemu+ssh://, qemu+tcp://, qemu+tls://, qemu+unix://. Prevents SSRF attacks.

📄

XML Escaping

All user inputs are XML-escaped before embedding in libvirt domain definitions. Prevents XML injection attacks.

🚫

Same-Origin Policy

No CORS layer configured. API only accepts requests from the same origin. Cross-origin requests are rejected by the browser.

⚙

Systemd Hardening

ProtectSystem=strict, NoNewPrivileges=true, PrivateTmp, ReadWritePaths restricted to /dev/pts and /var/lib/machina only.

API

API Design

RESTful JSON API with WebSocket real-time channels and Prometheus metrics

REST Endpoints

100+ endpoints under /api/v1 covering VMs, snapshots, networks, storage, node, templates, backups, host networking, and advanced operations.

WebSocket Channels

Real-time via /ws/v1: VM state watch, serial console, VNC proxy, SPICE proxy, SSH terminal. Heartbeat + change events.

Prometheus Metrics

Scrape-compatible export at /api/v1/prometheus. CPU, memory, disk, network per VM. Ready for Grafana dashboards.

Response Format

All endpoints return JSON with consistent structure. Domain XML configs return Content-Type: text/xml. Errors include machine-readable codes and human-readable messages. WebSocket messages use JSON with event-type discriminators.

Deployment

Deployment Options

From single-command install to production-hardened systemd service

Automated Install (Recommended)

# One-command install with 15-point verification
sudo ./install.sh

# Or via the deploy tool
./machinactl deploy

Detects Fedora/Ubuntu/Alma/RHEL, installs dependencies, builds Rust + web on the host, enables libvirt, configures systemd, runs verification tests.

Manual Build + Deploy

# Build everything
make all

# Install + start service
sudo make deploy

Builds release binaries (machina-daemon, machina-tui) and web frontend, installs to /usr/local, starts systemd service.

Systemd Service Architecture

machina-daemon.service

Main HTTP/WS server on port 5092. Hardened with ProtectSystem, NoNewPrivileges, PrivateTmp.

machina-backup.service

One-shot backup execution. Triggered by timer or API. Reads /etc/machina/backup.conf.

machina-backup.timer

Scheduled backup timer. Configurable interval. Activates backup.service on trigger.

Remote deploy (recommended)

scripts/deploy-remote.sh rsyncs sources to ~/.deployment/machina and runs cargo + npm on the SSH host (not on your laptop). Use USER@HOST or USER then HOST.

# Full install on remote
./scripts/deploy-remote.sh operator@10.0.0.5 --bind 0.0.0.0

# After rsync: compile-only smoke
./scripts/deploy-remote.sh operator@10.0.0.5 --remote-check
./scripts/deploy-remote.sh operator@10.0.0.5 --remote-build

# Quick: make release web + sudo make install (already on server)
./scripts/deploy-remote.sh operator@10.0.0.5 --quick

Ready to Deploy?

machina installs in under 5 minutes on any Linux host with KVM and libvirt. No containers, no orchestration overhead -- just a single binary and a systemd service.
