Licensing Model

HyperSDK Proprietary Software License.

License Type

machina is proprietary software owned by HyperSDK. It is not open source. All rights reserved. Distribution, modification, and reverse engineering are prohibited without explicit written permission from HyperSDK.

License Grant

Upon purchase, customers receive a non-exclusive, non-transferable license to use machina on the agreed number of hosts for the duration of the subscription period. The license includes software updates and support per the selected tier.

Restrictions

  • No redistribution or sublicensing
  • No reverse engineering or decompilation
  • No modification of binary or source code
  • No use beyond licensed host count
  • No sharing of API tokens or credentials

Compliance

  • License key validation on daemon startup
  • Host count enforcement per tier
  • Annual license renewal required
  • Audit rights reserved by HyperSDK
  • Grace period for renewal lapses

What's Included

Every tier includes the full machina platform. No feature gating on core functionality.

Web Dashboard

Full React-based web UI with dark and light themes, real-time status updates, and mobile responsive design.

machinactl CLI

Deploy, verify, health, and backup from the terminal. One-command host install and upgrade.

REST API

30+ API endpoints for complete VM lifecycle management. JSON responses, structured error handling.

VNC Console

In-browser noVNC console for direct graphical access to VMs. No external VNC client needed.

SSH & Serial Console

Browser-based SSH terminal and serial console via WebSocket. Access any VM from the dashboard.

VM Snapshots

Create, list, revert, and delete VM snapshots. Point-in-time recovery for all virtual machines.

Network Management

Create, edit, and delete virtual networks. DHCP configuration, IP range validation, bridge management.

Storage Management

Manage storage pools and volumes. Create, resize, and delete storage with overflow-safe calculations.

Live Metrics

Real-time CPU, memory, disk I/O, and network metrics per VM. Host hardware information display.

Dark / Light Theme

Toggle between dark and light themes in the web UI. User preference persisted across sessions.

VM Cloning

Clone VMs with automatic MAC address regeneration using dual-RandomState generation for uniqueness.

CD-ROM Management

Attach, detach, and swap ISO images on VM CD-ROM drives with path canonicalization security.
